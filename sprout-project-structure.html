三、一次 CLI 对话的执行链路

1 输入CLI / Web / Gateway 收到消息
2 Runtime解析会话、构造上下文、识别意图
3 AgentLoop模型生成或自动注入工具调用
4 ToolExecutor按风险策略检查工具
5 Approval高风险操作停车，CLI 三选项审批
6 Resume审批后恢复原 pending tool calls
7 Persist写入会话、事件、审计和派生车道

项目扫描能力

入口：ProjectAnalyzeTool

能力：语言/manifest/README/Docker/接口契约/数据库资产/图谱/知识项。

意图识别：8 种语言的“扫描项目/分析项目结构”会自动调用 project_analyze。

行数统计：git ✅ / rg ✅ / tokei ❌ / cloc ❌，缺失时使用 rg 文件清单做 fallback 估算。

Git 工具能力

只读：status、log、branch、diff、show、remote、tag、stash_list、rev_parse、ls_files。

写入：add、commit、pull、fetch、push、checkout/switch、branch、merge/rebase、reset/restore/revert、stash、tag、clone。

安全：只读 low risk；写入 high risk，需人工审批。broker 不支持的新操作会回落到结构化 git 命令。

多语言与审批

语言：中文、繁中、English、日本語、한국어、Русский、Español、Português。

审批 UI：Yes 本轮、Yes 同类、No 拒绝。

恢复：审批后恢复原任务，不创建新对话；模型失败时展示工具结果并按设置语言降级说明。

五、数据与控制流关系

authority

SQLite/Rootstock 保存会话、任务、审批、知识等权威数据。

cache

Redis 或 memory 作为热路径缓存，可重建。

vectors

Milvus/memory 保存 turn、知识、上下文向量，用于相似检索。

graph

Neo4j 或 disabled，用于关系投影。

context

上下文快照持久化，支持后续 intent 和检索增强。

blobs

大消息/附件落 blobstore，authority 中保留预览和 URI。

audit

审批、策略决策、安全事件记录。

trajectory

任务轨迹和演化证据材料。

六、当前演进重点

  • 审批交互已从纯 ID 文本改为 CLI 三选项，并解释权限内容。
  • 审批后恢复原任务，不新增“Continue”用户消息。
  • 流式路径审批不再打印旧英文句，而是把 approval metadata 交给 CLI。
  • 项目扫描意图已接入 8 种语言并自动调用工具。
  • Git 工具已扩展常用操作，并保留写操作审批边界。
  • 模型失败时不崩 CLI，显示工具结果和本地化降级说明。
